# invokes the ASGI `app` object directly, so uvicorn/gunicorn (only needed to

# has no HF_API_KEY configured, so /transcribe's primary Whisper engine is
# inactive and this is the only thing keeping the voice-input fallback (for
# browsers without native Web Speech API support) working. Don't drop it
# again without also setting HF_API_KEY, or the fallback goes dead silently.
